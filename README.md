# Insurance Management System

A desktop application for managing insurance clients, policies, and statistics, built with C# and Windows Forms.

## Features

- **Client Management** — register, edit, delete, search, and organize client records.
- **Insurance Policy Management** — create, edit, delete, search, and filter insurance policies.
- **Policy Status Tracking** — visually distinguish active and expired policies.
- **Dashboard** — view key statistics, including total clients, policies, and premiums.
- **Statistics** — review insurance-related data.
- **Data Export and Printing** — export client and policy data to CSV and print records.
- **Sorting and Filtering** — organize records by column, insurance type, and status.

## Technologies

- C#
- .NET Windows Forms
- Microsoft Access
- OleDb
- Git and GitHub

## Getting Started

1. Clone or download this repository.
2. Open `InsuranceManagementSystem.slnx` in Visual Studio.
3. Ensure the Microsoft Access Database Engine is installed.
4. Configure the Access database path as required by the application.
5. Build and run the project.

## Database

The application uses a Microsoft Access database (`.accdb`). A local database may be required to run the application. Do not commit databases containing personal or confidential information.

## Project Purpose

This project demonstrates desktop application development, database integration, CRUD operations, data validation, filtering, reporting, and user interface design in C#.
